プロフィール

独学からキャリアをスタートした元ニートの Web エンジニア。2015 年にエンジニアとしてのキャリアを開始し、現在はヘルスケア系サービスでテックリード兼 PdM/PjM として、開発統制・協業設計・採用までマルチハットで携わっています。10 年を超える開発経験を通じて、0→1 の立ち上げ、プロセス改善、ステークホルダーを巻き込んだ意思決定を得意としています。

得意領域

  • PHP / Laravel を中心にした Web アプリケーション開発とアーキテクチャ設計
  • PdM・PjM・スクラムマスターを兼務しながらチームをリードするアジャイル推進
  • テスト文化・レビュー文化の定着による品質改善と開発体験の向上
  • レガシーシステムのリファクタリングやリプレイスによる継続的改善

最近の取り組み

  • ヘルスケア領域プロダクトの統制と段階的リプレイス計画の策定・推進
  • 社内スケジュールおよび仕様統制、情シス的対応を兼ねたステークホルダー調整
  • AWS 運用改善・テスト戦略再構築・コードレビューによる品質担保
  • 0→1 プロジェクトやモノレポ化、CI/CD パイプライン再設計、学習コミュニティ運営

興味・関心

  • 学習: スクラム / アジャイル、プロダクトマネジメント、組織づくり、ドメイン駆動設計
  • 技術: Go, Rust などの静的型付け言語、観測性やプラットフォーム領域
  • 趣味: 音楽鑑賞、アニメ、読書、人間観察、DJ
